❓ Transaction ID (TrxID) কী?

Transaction ID হলো আপনার bKash/Nagad পেমেন্ট সফল হওয়ার পর পাওয়া একটি আলাদা নম্বর/কোড।

1. bKash/Nagad-এ পেমেন্ট করুন।
2. পেমেন্ট সফল হলে SMS বা অ্যাপের Transaction History/রসিদ দেখুন।
3. সেখানে TrxID বা Transaction ID লেখা যে নম্বর/কোডটি আছে, সেটি কপি করুন।
4. অর্ডার ফর্মের Transaction ID ঘরে সেটি লিখুন।
⚠️ আপনার PIN, OTP বা bKash/Nagad password কখনোই এখানে দেবেন না। শুধু Transaction ID দিন।
